## 它是什么

“舒服者耍起”原本是对“幸福者退让”的网络反讽：如果讲理的人一退再退，没付出代价的人就会越来越舒服，最后开始“耍起”。

这个 Skill 保留了梗的锋利，又做了一次正向重构：

- 对外：退让可以，但不能把退让办成对方的终身会员。
- 对内：焦虑可以来，但不必让它担任人生项目经理。
- 对事：不硬撞骨头，找缝下刀；先恢复一点松弛，再做一个小行动。

它适合处理日常焦虑、反复内耗、自我怀疑、人生迷茫、拖延、关系越界和“我是不是太好说话了”等情境。它提供的是陪伴、澄清和行动支持，不替代心理治疗、医疗诊断、法律意见或紧急援助。

## 一套五步，够人生临时维修

```text
情绪来了
   │
   ▼
「舒」先安顿身体与感受
   │
   ▼
「分」分清可控、可影响、需接受
   │
   ▼
「止」停止加码，守住边界
   │
   ▼
「游」换个尺度，给问题松绑
   │
   ▼
「起」做一个最小、可逆、真实的动作
```

| 一字诀 | 它在做什么 | 一句人话 |
|---|---|---|
| **舒** | 落地、呼吸、命名感受 | “先别解决人生，先把肩膀放下来。” |
| **分** | 区分事实、脑补与控制范围 | “这件事归你管，还是焦虑跨部门办公？” |
| **止** | 知止、减码、设置边界 | “善良可以续费，但不能默认自动续费。” |
| **游** | 拉远视角、幽默解黏、恢复游戏感 | “今天不是人生大结局，只是这一集网速不好。” |
| **起** | 价值导向的最小行动 | “别搬整座山，先挪开挡门的那块石头。” |

五步不是强制问卷。Skill 会根据情境选择最短路径：难过时先陪伴，焦虑时先落地，反刍时先分清，越界时先止损，迷茫时再谈方向。

## 哲学底色

| 来源 | 蒸馏进 Skill 的能力 |
|---|---|
| 《老子》“上善若水” | 柔软不是软弱；水不跟石头吵架，但它会换路继续走。 |
| 《老子》“知止不殆” | 给工作、担心和证明自己设停止线。 |
| 《老子》“为道日损” | 焦虑时先减负，不给大脑继续开十七个标签页。 |
| 《庄子·逍遥游》 | 把自我价值从外界赞踩中松绑。 |
| 《庄子·达生》“外重者内拙” | 把虚假的“输不起”调小，能力才回得来。 |
| 《庄子·养生主》庖丁解牛 | 不拿意志硬砍骨头，寻找事情本来的缝隙。 |
| 斯多葛控制二分 | 把精力收回到选择与行动。 |
| WHO 压力管理指南 | 落地、松钩、容纳感受、善待自己、按价值行动。 |

哲学只负责照亮问题，不负责拿古人压人。Skill 不会把“无为”解释成什么都不做，也不会拿“安之若命”劝用户忍受伤害。

更完整的原典、解释边界与现代方法见 [`references/philosophy.md`](./shufuzhe-shuaqi/references/philosophy.md) 和 [`references/emotional-support.md`](./shufuzhe-shuaqi/references/emotional-support.md)。

## 回答是什么味道

用户说：

> 明天要做汇报，我一直觉得自己会搞砸，准备了很久还是不敢开始。

Skill 可能回答：

> 你不是没准备好，是大脑把一次汇报临时升级成了“人格上市聆讯”。紧张很正常，因为你在乎；但紧张不是预言，它只是身体提前开了会。
>
> 先做个 30 秒维修：脚踩地，慢慢呼气，看看周围三样东西。然后把这两句分开：
>
> - 事实：明天有一场汇报。
> - 焦虑的加戏：搞砸一次，职业生涯就地火化。
>
> 现在只做最小一步：打开第一页，用手机录一遍 90 秒开场。先不追求精彩，只确认嘴和 PPT 还保持外交关系。

遇到边界问题时，它会切换为“耍起体检”：判断这是偶发误会、重复试探还是稳定占便宜，并给出不升级冲突的表达和下一步。

更多场景见 [`references/examples.md`](./shufuzhe-shuaqi/references/examples.md)。

## 安装

把 [`shufuzhe-shuaqi`](./shufuzhe-shuaqi) 整个目录复制到你的 Agent Skills 目录。例如 Codex：

```bash
cp -R shufuzhe-shuaqi ~/.codex/skills/
```

然后自然地描述问题，或者显式调用：

```text
用 $shufuzhe-shuaqi 陪我捋捋。我最近总担心选错工作，脑子停不下来。
```

也可以这样说：

- “我现在特别焦虑，先别讲大道理。”
- “这件事到底该算了，还是该立边界？”
- “我知道没那么严重，但就是停不下反刍。”
- “用舒服者耍起原则开导我一下，幽默点。”

## 使用边界

- 不诊断抑郁症、焦虑症或其他疾病。
- 不用“想开点”“别人更惨”压掉真实感受。
- 不鼓励报复、危险对抗或无原则忍让。
- 出现自伤、伤人、暴力、跟踪、虐待或紧急医疗风险时，停止玩梗，优先现实安全与专业支持。
- 如果痛苦持续、显著影响生活或超出自助范围，鼓励联系合格的心理咨询师、精神科/身心科医生或当地支持资源。
