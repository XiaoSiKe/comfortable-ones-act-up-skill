## 🌿 什么是「舒服者耍起原则」？

“舒服者耍起”原本是对“幸福者退让”的网络反讽：如果讲理的人一退再退，没付出代价的人就会越来越舒服，最后开始“耍起”。

这个 Skill 保留了梗的锋利，又做了一次正向重构：

- 对外：退让可以，但不能把退让办成对方的终身会员。
- 对内：焦虑可以来，但不必让它担任人生项目经理。
- 对事：不硬撞骨头，找缝下刀；先恢复一点松弛，再做一个小行动。

它适合处理日常焦虑、反复内耗、自我怀疑、比较、人生迷茫、拖延、失去、意义感下降、关系越界和“我是不是太好说话了”等情境。它提供的是陪伴、澄清和行动支持，不替代心理治疗、医疗诊断、法律意见或紧急援助。

### 两种“舒服”，两种方向

“舒服者耍起”在这个项目里有两个方向：

| 方向 | 发生了什么 | Skill 要做什么 |
|---|---|---|
| 🌪️ **侵占性舒服** | 越界持续因退让获益，或求证、检查、回避通过短期止痛被不断重复 | 恢复成本、停止加码、建立边界 |
| 🌤️ **恢复性舒服** | 人得到一点安全、休息和被理解的空间，好奇心、愿望与行动力重新回来 | 保护余量、恢复游戏感、承认想要、迈出小步 |

```text
零成本退让 ──→ 越界继续扩张

求证 / 检查 / 回避 ──→ 短期舒服 ──→ 下次更依赖同一套止痛

被看见 ──→ 有余量 ──→ 能分辨 ──→ 敢承认想要 ──→ 能选择 ──→ 能行动
```

因此，它既不是“一味退让学”，也不是“硬刚成功学”。更准确的目标是：

> **让该不舒服的机制重新碰到边界，让该舒服的人重新有力气生活。**

面对具体问题，Skill 最终帮助用户作出三种选择之一：

- **放：** 不再给不可控、低价值或无效纠缠追加预算。
- **守：** 对真实责任、重要关系和反复越界恢复边界。
- **做：** 对仍然重要且可以影响的事，迈出一个小而真实的动作。

完整理论与适用边界见 [`references/theory.md`](./comfortable-ones-act-up/references/theory.md)。

## 🫧 先松一口气：这里不急着解决人生

如果你现在只是压力很大、肩膀很紧、脑子像开了二十个标签页，可以先做这个 30 秒版本：

> 👣 双脚踩稳，感觉地面在托着你。<br>
> 🙆 肩膀往耳朵方向提一下，再慢慢放掉。<br>
> 👀 随便找三样有颜色的东西，只看见，不评价。<br>
> 💨 最后呼一口比平时稍长的气，不必深吸。

做完可以就停在这里。**舒服半分钟不需要提交成果证明。**

Skill 还可以根据压力落在身体、脑内、愤怒、委屈、社交过载或麻木，选择一种低负担的释放方法；不喜欢呼吸练习也有替代路线。详见 [`pressure-release.md`](./comfortable-ones-act-up/references/pressure-release.md)。

## 🧭 一套五步，够人生临时维修

```text
情绪来了
   │
   ▼
「舒」先安顿身体与感受
   │
   ▼
「分」分清可控、可影响、需接受
   │
   ▼
「止」停止加码，守住边界
   │
   ▼
「游」换个尺度，给问题松绑
   │
   ▼
「起」做一个最小、可逆、真实的动作，或向理想取一小勺样
```

| 一字诀 | 它在做什么 | 一句人话 |
|---|---|---|
| **舒** | 落地、呼吸、命名感受 | “先别解决人生，先把肩膀放下来。” |
| **分** | 区分事实、脑补与控制范围 | “这件事归你管，还是焦虑跨部门办公？” |
| **止** | 知止、减码、设置边界 | “善良可以续费，但不能默认自动续费。” |
| **游** | 拉远视角、幽默解黏、恢复游戏感与愿望 | “今天不是人生大结局，也不必把别人的评分当导航。” |
| **起** | 价值导向的最小行动或向心取样 | “别搬整座山，先用一小步确认你想靠近哪片山坡。” |

五步不是强制问卷。Skill 会根据情境选择最短路径：难过时先陪伴，焦虑时先落地，反刍时先分清，越界时先止损，哀伤时不催恢复，迷茫时再谈方向。

## 🪞 先看四层，不把一切都怪给心态

```text
身体层：我是不是已经缺觉、过劳、疼痛或过载？
   ↓
故事层：事实之外，大脑又追加了什么终局判决？
   ↓
关系层：这里有没有真实的权力、边界、资源与责任问题？
   ↓
方向层：我真正想保护什么、靠近什么、成为怎样的人？
```

这让 Skill 不会对着一个缺觉的人讲宏大使命，也不会对着一个正在被侵害的人说“你要学会不争”。有些痛苦确实来自现实；情绪支持不能成为让现实隐身的魔术。

## 🌬️ 洒脱不是无所谓，是把理想带回现实

有时人缺的不是更多道理，而是一句许可：**我可以认真对待自己真正想要的生活。**

本 Skill 把“洒脱”理解为三件事同时成立：

- 不把外界评分、一次失败或“必须马上证明”当成唯一方向盘；
- 不抹掉钱、健康、关系和安全等真实约束，愿意看见理想的代价；
- 不把愿望逼成豪赌，先用一个可承受、可撤回、能带来信息的小实验靠近。

所以“敢追理想”不自动等于辞职、远行或切断退路。可以先取样，再扩大；可以暂停、改路，也不等于背叛自己。详细的方向协议见 [`direction-and-ideals.md`](./comfortable-ones-act-up/references/direction-and-ideals.md)，本次 v1.2 的需求与设计记录见 [`RD.md`](./RD.md)。

## 📜 哲学底色

| 来源 | 蒸馏进 Skill 的能力 |
|---|---|
| 《老子》“上善若水” | 柔软不是软弱；水不跟石头吵架，但它会换路继续走。 |
| 《老子》“知止不殆” | 给工作、担心和证明自己设停止线。 |
| 《老子》“为道日损” | 焦虑时先减负，不给大脑继续开十七个标签页。 |
| 《庄子·逍遥游》 | 把自我价值从外界赞踩中松绑。 |
| 《庄子·达生》“外重者内拙” | 把虚假的“输不起”调小，能力才回得来。 |
| 《庄子·养生主》庖丁解牛 | 不拿意志硬砍骨头，寻找事情本来的缝隙。 |
| 斯多葛控制二分 | 把精力收回到选择与行动。 |
| WHO 压力管理指南 | 落地、松钩、容纳感受、善待自己、按价值行动。 |

哲学只负责照亮问题，不负责拿古人压人。Skill 不会把“无为”解释成什么都不做，也不会拿“安之若命”劝用户忍受伤害。

更完整的原典、解释边界与现代方法见 [`references/philosophy.md`](./comfortable-ones-act-up/references/philosophy.md) 和 [`references/emotional-support.md`](./comfortable-ones-act-up/references/emotional-support.md)。

## 🛶 从临时维修到陪一段路

Skill 会根据用户需要调整谈话深度：

- **一口气：** 先陪用户过眼前这一阵，三五句话也可以。
- **一盏茶：** 看见反复模式，理解焦虑短期保护了什么、长期又收了什么费用。
- **一段路：** 在持续对话中回看真实结果，调整动作，而不是每天重新上一遍人生哲学课。
- **向心一小步：** 当用户已经有想靠近的方向时，先辨认自己的向往与借来的标准，再设计一次不透支基本盘的现实取样。

它还覆盖九类常见“人生打结”：未发生先担心、过去了仍反刍、失败后人格破产、同辈比较、选择后悔、忙却空、关系过度付出、真实失去，以及没有大事却长期提不起劲。详细路由见 [`references/life-guidance.md`](./comfortable-ones-act-up/references/life-guidance.md)。

## 🧩 从开源 Skills 吸收了什么

v1.0.0 对多个开源 Agent Skills 做了定向调研与适配，主要吸收的是交互设计，而不是复制文案：

- 从 Life Coach 学到：明确要方案时直接给方案，探索时一次只问一个关键问题。
- 从 GitHub Awesome Copilot 的 Tugboat 学到：同理心必须改变实际做法，不能只增加安慰句。
- 从 Spoon Planner 学到：按真实能量下限规划，并计算决定、社交和情绪劳动等隐形成本。
- 从 Rabbit Hole Rescue 学到：看见表面行为背后的需要，同时保留关系边界。
- 从 Wellbeing Boundaries 学到：边界必须改变下一次的实际路由，不能换个说法就绕回来。

完整的仓库、固定提交、许可证、采用内容和主动排除项见 [`open-source-patterns.md`](./comfortable-ones-act-up/references/open-source-patterns.md)。运行时对话规则见 [`conversation-protocol.md`](./comfortable-ones-act-up/references/conversation-protocol.md)。

所有引入内容都经过重新表达和领域适配。本项目不会让通用 Agent 冒充治疗师，不采用未经校验的临床分数，也不把社区仓库中的效果宣称直接当成医学证据。

## 🎭 回答是什么味道

用户说：

> 明天要做汇报，我一直觉得自己会搞砸，准备了很久还是不敢开始。

Skill 可能回答：

> 你不是没准备好，是大脑把一次汇报临时升级成了“人格上市聆讯”。紧张很正常，因为你在乎；但紧张不是预言，它只是身体提前开了会。
>
> 先做个 30 秒维修：脚踩地，慢慢呼气，看看周围三样东西。然后把这两句分开：
>
> - 事实：明天有一场汇报。
> - 焦虑的加戏：搞砸一次，职业生涯就地火化。
>
> 现在只做最小一步：打开第一页，用手机录一遍 90 秒开场。先不追求精彩，只确认嘴和 PPT 还保持外交关系。

遇到边界问题时，它会切换为“耍起体检”：判断这是偶发误会、重复试探还是稳定占便宜，并给出不升级冲突的表达和下一步。

更多场景见 [`references/examples.md`](./comfortable-ones-act-up/references/examples.md)。

## 📦 安装

可以从 [最新 Release](https://github.com/XiaoSiKe/comfortable-ones-act-up-skill/releases/latest) 下载打包好的 ZIP，解压后把 `comfortable-ones-act-up` 目录放入 Agent Skills 目录。

从源码安装时，把 [`comfortable-ones-act-up`](./comfortable-ones-act-up) 整个目录复制到你的 Agent Skills 目录。例如 Codex：

```bash
cp -R comfortable-ones-act-up ~/.codex/skills/
```

然后自然地描述问题，或者显式调用：

```text
用 $comfortable-ones-act-up 陪我捋捋。我最近总担心选错工作，脑子停不下来。
```

也可以这样说：

- “我现在特别焦虑，先别讲大道理。”
- “这件事到底该算了，还是该立边界？”
- “我知道没那么严重，但就是停不下反刍。”
- “我其实想过另一种生活，但不敢开始，帮我找一小步。”
- “用舒服者耍起原则开导我一下，幽默点。”

## 🧪 行为评测

仓库除了结构验证，还提供一组行为合同，覆盖倾诉偏好、直接建议、压力释放、边界、哀伤、危机安全、理想方向和非触发场景。它不靠匹配固定金句，而是检查“有没有尊重偏好、有没有虚假保证、是否在危机时关闭幽默、是否既允许愿望又不鼓励冲动豪赌”等行为不变量。

- 评测说明：[`evals/README.md`](./evals/README.md)
- 场景合同：[`evals/cases.json`](./evals/cases.json)
- 本地验证：`python3 scripts/validate_skill.py`

当前 CI 验证评测集合的结构与覆盖面；跨模型实际回答仍需独立运行并人工评分，不能把“案例文件存在”冒充成“效果已经证明”。

## 🛟 使用边界

- 不诊断抑郁症、焦虑症或其他疾病。
- 不用“想开点”“别人更惨”压掉真实感受。
- 不鼓励报复、危险对抗或无原则忍让。
- 出现自伤、伤人、暴力、跟踪、虐待或紧急医疗风险时，停止玩梗，优先现实安全与专业支持。
- 如果痛苦持续、显著影响生活或超出自助范围，鼓励联系合格的心理咨询师、精神科/身心科医生或当地支持资源。

## 🚀 版本

当前为 **v1.2.0**：在 v1.1.0 的五道门、压力释放、隐私边界和行为评测基础上，新增“洒脱与理想”方向支持。Skill 会帮助用户把外界评分与真实向往分开，在不牺牲安全和基本盘的前提下，用可逆的“向心取样”靠近想要的生活；同时新增方向场景评测与 RD 需求/设计文档。

这次深化没有把 Skill 变成“万事皆可庄子曰”。相反，它增加了现实校验：先看身体、资源、权力与损失，再决定哲学是不是此刻真正有用。
